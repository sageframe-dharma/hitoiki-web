# Home page direction

Accepted in the working conversation: use the supplied Hitoiki mark, Palana's
warm, flat visual family, and QuickCMD's compact, direct product demonstration.
The practitioner explicitly asked to begin building after settling the name,
icon, audience, tone, and page reference. This is the fixed direction, rather
than an open identity exercise.

Build directly in static code. Show the command interaction immediately. Keep
SSH and remote sudo concrete, and describe the manual coding-agent handoff in
three steps. Do not imply agent integration or security enforcement. State
unreleased status, and add verified app download/purchase URLs only when ready.

The design uses native-style system text and small monospace commands, as in
the pinned Palana site. Code-led implementation, no generated comp or imagery.
Review desktop and narrow layouts when the available browser permits it; report
the actual scope of verification.
