Use the SSH setup
you already have.

Hitoiki runs SSH commands through your shell, using your existing ~/.ssh/config, host aliases, keys, and SSH agent. Type the complete command, just as you would in a terminal.

ssh server 'df -h' ssh -tt server 'sudo systemctl status nginx --no-pager'

Password prompts work in the panel. Input is forwarded to the running command, and password entry respects terminal echo settings. If remote sudo needs a terminal, Hitoiki offers to retry with -tt.

SSH and sudo documentation

Your agent gives you
a command to run.

Keep your coding agent's permissions restricted. When a command needs access to your Mac or a remote host, run it yourself in Hitoiki.

  1. Copy the command from the conversation.
  2. Paste it into Hitoiki, review it, and press Return.
  3. Copy the result back to your agent.

This works with any agent that gives you command text, including commands using SSH or sudo. You choose what runs and enter any required password yourself.

Frequently asked questions.

Is Hitoiki free?

Yes. The app and MIT-licensed source are free on GitHub. The optional Payhip purchase supports development and provides the same app.

Can it run SSH commands and sudo?

Yes. Hitoiki uses your installed SSH client, configuration, keys, and agent. Password prompts work in the panel; remote sudo can request a terminal with ssh -tt. Read about password input.

Does it include AI?

No. Hitoiki runs the command text you enter. You can paste a command from any coding agent, run it yourself, and copy the output back. No AI account or integration is required.

Does it replace Terminal?

Use Hitoiki for short commands. Use a terminal for persistent sessions, full-screen applications such as Vim or htop, and work that needs a complete terminal emulator.

Does Hitoiki phone home?

Only to check GitHub for a newer version. Automatic update checks can be turned off in Settings.

Does Hitoiki save passwords or transcripts?

Interactive password input is forwarded to the running program and is not saved by Hitoiki. Transcripts stay in memory. Normal SSH and sudo password prompts disable echo, so the password does not appear in the output. Privacy details.

Which Macs does it run on?

Hitoiki requires macOS 14 or later. It uses the shell and OpenSSH client already installed on your Mac.
