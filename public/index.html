The app itself.

Use the SSH setup
you already have.

Hitoiki runs SSH commands through your shell, using your existing ~/.ssh/config, host aliases, keys, and SSH agent. Type the complete command, just as you would in a terminal.

ssh server 'df -h' ssh -tt server 'sudo systemctl status nginx --no-pager'

Password prompts work in the panel. Input is forwarded to the running command, and password entry respects terminal echo settings. If remote sudo needs a terminal, Hitoiki offers to retry with -tt.

SSH and sudo documentation

Run it yourself.

Hitoiki runs only the command text you enter, and you choose when. That makes it a simple way to keep a coding agent's permissions restricted: when the agent needs a command run on your Mac or a remote host, you run it.

  1. Copy the command from the conversation.
  2. Paste it into Hitoiki, review it, and press Return.
  3. Copy the result back to your agent.

This works with any agent that gives you command text, including commands using SSH or sudo. Hitoiki does not connect to the agent or grant it access, and you enter any required password yourself.

Frequently asked questions.

Is Hitoiki free?

Hitoiki is open source under the MIT license. You can build it yourself for free. The signed, notarized Mac download costs $6 and supports continued development. Both are the same code. Building from source.

Can it run SSH commands and sudo?

Yes. Hitoiki uses your installed SSH client, configuration, keys, and agent. Password prompts work in the panel; remote sudo can request a terminal with ssh -tt. Read about password input.

Does it include AI?

No. Hitoiki runs the command text you enter. You can paste a command from any coding agent, run it yourself, and copy the output back. No AI account or integration is required.

Does it replace Terminal?

Use Hitoiki for short commands. Use a terminal for persistent sessions, full-screen programs such as vim, htop and tmux, and work that needs a complete terminal emulator.

Does Hitoiki phone home?

Only to ask GitHub for the latest version number, when it opens and once a day while it runs. It sends only its name and version, and nothing about you or your commands. You can turn the check off in settings.

Does Hitoiki save passwords or output?

No. Password input goes to the running program and is not saved by Hitoiki. Output stays in memory and is never saved. Normal SSH and sudo password prompts hide your typing, so the password does not appear in the output. Command history is off by default. Privacy details.

Which Macs does it run on?

Hitoiki requires macOS 14 or later. It uses the shell and OpenSSH client already installed on your Mac.
